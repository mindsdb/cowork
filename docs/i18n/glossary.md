# Glossary and style

Every translation follows this page. When a term here appears in English, use exactly this translation. Add a row when you fix a translation for a product concept that will come up again. Native-speaker reviewers (ENG-4149 phase 4) own the final word.

## Tone

| | Spanish (`es`) | Portuguese (`pt-BR`) |
|---|---|---|
| Variant | Neutral Latin American: no *vosotros*, no regionalisms (*computadora*, not *ordenador*) | Brazilian |
| Address | Informal **tú** (*elige*, *tu tema*) | **você** (*escolha*, *seu tema*) |
| Buttons and actions | Infinitive (*Guardar*, *Subir logo*) | Infinitive (*Salvar*, *Enviar logo*) |
| Hints and instructions | Imperative (*Elige un color…*) | Imperative (*Escolha uma cor…*) |
| Sentence case | Same as English: capitalize only the first word and proper nouns | Same |

## Never translate

Anton · MindsHub · Cowork · a deployment's brand name · model and provider names (Claude, GPT, Gemini, Jev) · file formats (PNG, SVG, PDF, KB, MB) · `8-Bit` · keyboard keys.

## Japanese (`ja`)

### Style

| | Japanese |
|---|---|
| Register | Polite and concise, like Apple's and Google's Japanese UIs: **です・ます** in sentences, never casual, no excessive keigo (no 〜させていただきます) |
| Buttons and actions | Short noun or verb stem, no です・ます (*保存*, *削除*, *キャンセル*, *再試行*, *ロゴをアップロード*) |
| Hints and instructions | です・ます; 〜してください only for a real instruction (*色を選択してください*), otherwise state it (*変更は自動的に保存されます*) |
| Errors | Say what happened, politely: *保存できませんでした*, *接続できませんでした* |
| Punctuation | Full-width 。、 in Japanese sentences; 「」 for quoted UI labels; （） around Japanese text; keep `…` for "in progress" (*読み込み中…*) |
| Spacing | No spaces between Japanese and Latin words or numbers (*Anton に* → *Antonに*), except where a variable or brand reads better spaced in a long line |
| Plurals | Japanese has no plural: write only the `other` branch, with a counter (`{count, plural, other {#件}}`, `#個`, `#人`, `#回`, `#分`, `#秒`) |
| Word order | Rewrite the sentence; don't follow English order. Variables can move anywhere in the message |
| Katakana | Use the standard katakana IT term where Japanese software does (タスク, プロジェクト); prefer a native word where one is standard (設定, 削除, 検索) |
